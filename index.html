Material für die Arbeit im Kurs

  • Ein kurzer Konzepttext als Gesprächsgrundlage
  • Eine Einschätzung, was im eigenen Portfolio bereits sichtbar ist und was noch fehlt
  • Ein realer Anker: Foto, Ort, Objekt, Körper, Archiv, Interview, Skizze oder eigenes Material
  • Ein passender Test: Modellvergleich, Editing, Storyboard, ComfyUI, Tool, Agent oder hybride Aufnahme
  • Beobachtungen zu Licht, Material, Konsistenz, Rechtefragen, Drift, Bewegung oder Produktwahrheit
  • Eine Form, in der Ergebnis und Vorgehen nachvollziehbar gezeigt werden können

Workflow-Canvas ohne großes Budget

Günstige Wege für Weavy-ähnliche Prozesse

Ein Weavy-ähnlicher Workflow braucht Rollen für Eingaben, sichtbare Zwischenschritte, Vergleichbarkeit, Wiederholbarkeit und eine saubere Übergabe. Die Oberfläche ist zweitrangig.

SetupKostenlogikGeeignet fürGrenze
ComfyUI lokalSoftware kostenlos; Kosten entstehen durch Hardware, Speicher und Zeit.Nodebasierte Bild- und Video-Workflows, FLUX/Stable Diffusion/Wan, Control, Inpainting, Batchtests.Setup, Custom Nodes und Modellverwaltung brauchen technische Geduld.
ComfyUI + Cloud GPUPay-per-use über GPU-Anbieter oder gehostete ComfyUI-Services.Studierende ohne lokale GPU, Renderphasen, Video-Workflows.Kostenkontrolle braucht Testlimits und kurze Clips.
Krea NodesFree Plan mit Compute-Units; Pro/Max für mehr Modelle, Video und Workflow Automation.Canvas-Tests, Bild/Video-Modellvergleich, Node Apps, Prototypen für Präsentationen.Weniger offen als ComfyUI; Kosten hängen an Compute-Units.
Luma Workspace / AgentsFree Trial Credits; Individual-Pläne starten laut Luma bei 30 USD/Monat.Video, Bild-zu-Video, Agents, Team- und Projektorganisation.Veo/Kling/Agents verbrauchen Credits je nach Länge und Anzahl der Versuche.
fal.ai / ReplicatePay-per-output oder pay-per-second; Preise pro Modell prüfen.Vergleich verschiedener Modelle, eigene kleine Apps, Netlify-Demos, API-basierte Filtertools.Kein fertiger Design-Canvas; API-Kosten müssen vorab geschätzt werden.

Setup A: komplett lokal

ComfyUI + lokale Modelle + lokale Ordnerstruktur. Geeignet, wenn der Workflow selbst Teil des Portfolios ist.

Input Folder
→ Reference Images
→ Mask / Control / Prompt
→ Model Node
→ Upscale / Edit
→ Contact Sheet
→ Auswahl + QA

Setup B: lokal planen, Cloud rendern

Workflow zuerst als Diagramm oder ComfyUI-JSON planen. Cloud-Runs nur für definierte Frames oder kurze Clips.

Storyboard
→ 3 Testframes lokal
→ 1 Cloud-Render pro Shot
→ Fehlerliste
→ gezielte Revision
→ Exportset

Setup C: Agent + Canvas

n8n, Gemini, Codex oder ein kleines Script sammelt Quellen, baut Briefings, prüft Dateinamen und erstellt QA-Listen. Die visuelle Produktion bleibt im passenden Bild- oder Videotool.

Research Agent
→ Briefing Sheet
→ Prompt Variants
→ Model Test Log
→ QA Checklist
→ Case Page Draft

Workflow-Aufgabe für Weavy-orientierte Projekte

01 InputProduktfoto, eigene Fotografie, Skizze, Referenzset, Brand-Regeln, Zielkanal.
02 RollenBase Image, Style Reference, Product Lock, Mask, Prompt, Negative, QA Criteria.
03 ModelltestEin Brief, drei Systeme: ComfyUI, Krea/Luma, fal.ai oder Replicate.
04 BewertungPrompttreue, Produktwahrheit, Licht, Kanten, Text, Kosten, Wiederholbarkeit.
05 HandoffFinale Assets, Workflowdiagramm, Kostenlog, Fehlerliste, Case-Text.

Portfolio-Ziel: Ergebnis, Eingaben, Entscheidungen, Grenzen und Wiederholbarkeit gemeinsam zeigen.

Asset Replacement

  1. Produktfoto freistellen oder maskieren.
  2. Base Scene definieren: Licht, Perspektive, Kontaktflächen.
  3. Produktgeometrie sperren: Größe, Farbe, Logo, Material.
  4. Varianten erzeugen: Hintergrund, Modell, Kanalformat.
  5. QA: Schatten, Kanten, Reflexe, Branding, Text, Dateinamen.

Storyboard zu Animatic

  1. 6-12 Stills mit stabiler Figur, Raumlogik und Brennweite.
  2. Pro Frame ein kurzer Video-Prompt: Bewegung, Kamera, End State.
  3. Clips auf 4-8 Sekunden begrenzen.
  4. Schnitt mit Raumton, harter Auswahl und Colorgrade.
  5. Case Page mit Frames, Clips, Fehlern, Soundnotiz.

AI Postproduction

  1. Ausgangsbild und Editziel festlegen.
  2. LOCK-Liste schreiben: Gesicht, Pose, Licht, Text, Geometrie.
  3. Eine Veränderung pro Revision.
  4. Physik prüfen: Schattenrichtung, Grain, Kanten, Material.
  5. Vorher/Nachher und Entscheidungslog dokumentieren.

Brand-DNA-System

  1. Bildsprache aus Website, Social, Produkt und Kampagne extrahieren.
  2. Regeln formulieren: Farbe, Licht, Typografie, Motive, Ton.
  3. Pomelli oder eigenes Board testen.
  4. Ausschlussregeln schreiben: Welche Motive, Tonalitäten und Bildcodes passen nicht?
  5. Formatset: Hero, Social, OOH, Produktdetail, Motion.

Preisstand kann sich ändern. Für API- und Compute-Kosten immer vor dem Test die Modellseite prüfen und ein Run-Limit festlegen.

Agenten brauchen Kriterien, Quellen, Grenzen und ein prüfbares Ausgabeformat.

Beispiel: Blumen im Wasser

Aus einem künstlerischen Konzept wird ein testbarer Bildbrief.

PLACE
Small bathroom at dusk, weak window light from the left, pale green tiles, condensation on the mirror.

FOCUS
A single white flower submerged in a glass bowl of water on the sink.

FACTS
Petals pressed slightly downward by water, tiny air bubbles clinging to the stem, warped reflection in the wet mirror, slow ripples, chipped porcelain edge, 50mm documentary still, shallow depth of field, muted grey-green palette.

FORM
Photographic storyboard frame for a project about memory, emotional drift and the loss of clear form.

FORBIDDEN
No botanical studio look, no perfect product lighting, no fantasy glow, no extra flowers, no text, no watermark.
